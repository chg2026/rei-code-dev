The Reminders feature needs to be rebuilt from scratch. Here are all the issues to fix in one pass:

---

**1. FIX TIMEZONE BUG (critical)**
Reminders are being saved a day early. The bug is a classic UTC offset issue — dates are being stored or parsed as UTC midnight which rolls back one day for EST users.

Fix: When saving a reminder date, store it as a date-only string (YYYY-MM-DD) with no time component, OR store with the user's local timezone offset. When displaying, always parse dates in the user's local timezone, never as UTC midnight. Add `timeZone: Intl.DateTimeFormat().resolvedOptions().timeZone` to any date formatting calls. This should auto-detect the user's timezone.

---

**2. REMINDER DATA MODEL — add these fields if not already present**
The reminder should support:
- `title` (string, required)
- `notes` (string, optional)
- `tags` (string array, optional)  
- `dueDate` (date, required — the day of the reminder)
- `dueTime` (time string optional — e.g. "09:00" — for alarm)
- `urgency` (enum: low | medium | high | urgent)
- `dismissed` (boolean — whether the user clicked to dismiss the pop-up)
- `completedAt` (timestamp, nullable)

Run any needed DB migration with raw SQL + prisma generate.

---

**3. REMINDER CREATION — on the Calendar page**
Add a "+ New reminder" button at the top of the Calendar page (next to the page title).

Clicking it opens a modal/slide-over with these fields:
- Title (text input, required)
- Notes (textarea, optional)
- Tags (multi-tag input — type and press Enter to add a tag)
- Date (date picker, required)
- Time / Alarm (time picker, optional — "Set an alarm for this reminder")
- Urgency (segmented control or dropdown: Low / Medium / High / Urgent)

"Save reminder" button creates it. Modal closes. Reminder appears in the Active Reminders section.

- Show all reminders that are not yet dismissed/completed

- Clicking a reminder row opens an inline edit panel (NOT redirecting to Command Center) — same modal used for creation, pre-filled with the reminder's data
- Clicking ✓ marks it dismissed/completed and removes it from Active list
- Add an "Overdue" label for reminders past their due date (already exists, keep it)

**5. POP-UP NOTIFICATION for due reminders**
Build a global notification system (add it to the root layout so it works on any page):

- On app load and every 60 seconds, check if there are any reminders where `dueDate` is today AND `dismissed = false`

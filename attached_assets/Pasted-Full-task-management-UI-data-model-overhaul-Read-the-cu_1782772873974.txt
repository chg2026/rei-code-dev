Full task management UI + data model overhaul. Read the current WsTask model and My Tasks page before making changes, then implement everything below.

**PART 1 — DATA MODEL**

**1a. Multiple assignees**
Check if WsTask already has a WsTaskAssignee junction table. If not:
- Create model WsTaskAssignee: id, taskId (FK → WsTask cascade), userId (FK → User cascade), assignedAt DateTime
- Raw SQL: CREATE TABLE "WsTaskAssignee" (id TEXT PRIMARY KEY DEFAULT gen_random_uuid()::text, "taskId" TEXT NOT NULL REFERENCES "WsTask"(id) ON DELETE CASCADE, "userId" TEXT NOT NULL REFERENCES "User"(id) ON DELETE CASCADE, "assignedAt" TIMESTAMPTZ DEFAULT now(), UNIQUE("taskId","userId"));
- Add relation to WsTask schema: `assignees WsTaskAssignee[]`
- Run migration + prisma generate
- Keep any existing single assigneeId field for now, we'll migrate data

**1b. Task status enum**
Replace boolean "completed" with a status field. Add to schema:
enum WsTaskStatus { NotStarted InProgress InReview Done Cancelled }
Raw SQL:
```sql
CREATE TYPE "WsTaskStatus" AS ENUM ('NotStarted','InProgress','InReview','Done','Cancelled');
ALTER TABLE "WsTask" ADD COLUMN IF NOT EXISTS "status" "WsTaskStatus" DEFAULT 'NotStarted';
```
Run migration + prisma generate.

**1c. Private "My Workspace" tasks**
```sql
ALTER TABLE "WsTask" ADD COLUMN IF NOT EXISTS "isPrivate" BOOLEAN DEFAULT false;
```
Private tasks: visible only to creator, no department required.
Run migration + prisma generate.

**PART 2 — API UPDATES**

Update `POST /api/workspace/tasks`:
- Accept `assigneeIds: string[]` (array of user IDs) — create WsTaskAssignee rows for each
- Accept `status: WsTaskStatus` (default NotStarted)
- Accept `isPrivate: boolean` (default false)

Update `PATCH /api/workspace/tasks/[id]`:
- Accept `assigneeIds: string[]` — diff against existing assignees, add/remove accordingly
- Accept `status: WsTaskStatus`
- Accept `isPrivate: boolean`

Update `GET /api/workspace/tasks`:
- Include `assignees: { user: { id, name, avatarUrl } }[]` in response
- Include `status`, `isPrivate`, `space: { id, name, color }` in response
- Add query param `?view=all|private|assignedOut`
  - all: all non-private tasks for the company where user is assignee or creator
  - private: isPrivate=true AND createdById=currentUser
  - assignedOut: tasks created by currentUser assigned to others (existing behavior)
- Add query param `?userId=` to filter by specific assignee

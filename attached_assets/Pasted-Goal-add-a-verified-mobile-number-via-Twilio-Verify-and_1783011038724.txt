normalizeUsPhone(raw: string): string | null — returns E.164 for a valid US number (10 digits → +1XXXXXXXXXX; also accept an existing +1XXXXXXXXXX); returns null if not a valid US mobile.
startPhoneVerification(phoneE164: string) — calls client.verify.v2.services(VERIFY_SID).verifications.create({ to: phoneE164, channel: "sms" }).
checkPhoneVerification(phoneE164, code): Promise<boolean> — calls verificationChecks.create({ to, code }) and returns true only when status === "approved".
isVerifyConfigured(): boolean.
